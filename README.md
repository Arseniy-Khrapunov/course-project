# Симулятор управления космической станцией

Курсовой проект. Текстовая игра, где игрок управляет космической станцией.

**Студент:** Храпунов Арсений Алексеевич, группа ПИ-53
**Преподаватель:** Рахманин Данила Сергеевич, Троицкий Виктор Сергеевич

## Что делает программа

Игрок запускает игру и получает базовую станцию. На каждом ходу он видит отчёт:
сколько осталось энергии, еды и кислорода, в каком состоянии модули и экипаж.
Потом вводит команду — построить отсек, отправить инженера чинить реактор,
дать экипажу отдохнуть. Если вовремя не реагировать на поломки и нехватку
ресурсов, станция может выйти из строя, и игра закончится.

Цель — продержаться как можно дольше.

## Наследование

- `Module` — базовый класс. Наследники: `LivingModule`, `Laboratory`, `Reactor`.
- `CrewMember` — базовый класс. Наследники: `Engineer`, `Scientist`, `Doctor`.
- `Resource` — ресурсы (еда, энергия, кислород).
- `Event` — события (метеорит, поломка).
- `Station` — главный класс, хранит модули и экипаж.

## Две версии

Сначала пишу на C++, потом на Java. Это две отдельные программы

## Как собрать и запустить

### C++

```bash
cd cpp-version
g++ src/*.cpp -Iinclude -o station
./station
```

### Java

```bash
cd java-version
javac -d build src/main/java/com/station/*.java
java -cp build com.station.Main
```

## Что нужно

- C++17 или новее
- JDK 17 или новее
- g++ и javac
